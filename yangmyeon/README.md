# 양면

테니스 코트 **옆(네트 연장선)** 에 카메라 하나를 세워 **양쪽 코트를 한 프레임에** 담는다.
네트가 화면 가운데 수직으로 서고 두 코트가 좌우로 나뉘므로, 점수는 화면 좌/우를 눌러 센다.
포인트마다 영상 타임코드를 남겨서, 나중에 그 랠리로 바로 점프할 수 있다.

## 왜 울트라와이드 하나인가

코트 전체 길이 **23.77 m** 를 한 프레임에 담아야 한다.

| 렌즈 | 가로 화각 | 필요 거리 |
|---|---|---|
| **울트라와이드 13 mm** | **108.3°** | **8.58 m** |
| 메인 26 mm | 69.4° | 17.17 m — 클럽 코트에선 불가 |

ITF 권장 코트의 측면 펜스는 중앙선에서 **9.14 m**. 울트라와이드 최소 거리보다 **0.56 m 여유**다.
9.15 m 에 두면 가로 25.34 m 가 들어와 베이스라인 밖으로 0.78 m 여백이 생긴다.

애플 표기 "120°" 는 **대각** 118° 이고 가로는 108.3° 다. 이 앱의 계산은 가로 기준이다.

## Xcode 프로젝트 만들기

1. **File → New → Project → iOS → App** · SwiftUI · Swift
2. 생성된 `ContentView.swift` 와 `...App.swift` 를 **지운다.**
3. `App/` 의 9개 파일과 `Sources/MatchCore/` 의 2개 파일을 끌어다 넣는다
   (Copy items if needed 체크).
4. `import MatchCore` 두 줄을 지운다 — 직접 넣었으니 같은 모듈이다
   (`ContentView.swift`, `MatchLog.swift`, `Sheets.swift`).
5. **Info.plist 에 추가** — 없으면 실행 즉시 죽는다.

   | 키 | 값 |
   |---|---|
   | `NSCameraUsageDescription` | 코트를 촬영합니다. |
   | `NSMicrophoneUsageDescription` | 경기 소리를 함께 녹음합니다. |

6. **가로 전용으로 고정.** 코트가 가로로 길어서 세로로 쓸 일이 없다.
   Target → General → Supported Orientations 에서 **Landscape Left/Right 만** 체크.
7. Signing & Capabilities 에서 본인 Apple ID 로 팀 선택(무료 계정 가능).
8. 실기기 연결해 실행.

## 설치

ⓘ 버튼을 누르면 **고른 렌즈의 실제 화각으로 계산한 안내**가 나온다.

| | |
|---|---|
| 위치 | 코트 옆, **네트 연장선** |
| 중앙선에서 | 최소 **8.58 m** · 권장 **9.2 m 이상** |
| 높이 | **2 m 이상.** 높을수록 선수가 겹쳐 보이지 않는다 |
| 방향 | 네트가 화면 가운데 점선에 맞게 |
| 확인 | 양쪽 베이스라인이 좌우 흰 점선 안에 |

화면에 안내선이 깔린다 — 가운데 세로 점선(네트), 좌우 흰 점선(베이스라인 한계),
코트 평면이 앉을 띠. 상단 격자 버튼으로 끈다.

### 가까운 코트와 먼 코트의 차이

측면 한 대로 찍는 구조상 생긴다. 키 1.75 m · 4K 세로 2160 px 기준:

| 위치 | 카메라까지 | 화면에서 |
|---|---|---|
| 가까운 쪽 네트 앞 | 9.4 m | 약 270 px |
| 가까운 쪽 베이스라인 | 15.0 m | 약 169 px |
| 먼 쪽 네트 앞 | 20.2 m | 약 125 px |
| 먼 쪽 베이스라인 | 23.4 m | 약 108 px |

**약 2.5배 차이.** 4K 로 찍으면 좌우 반씩 잘라 **코트당 1920×2160** 이 남는다.

## 중단을 전제로 만들었다

코트에 두고 두 시간을 돌린다. 전화·제어센터·다른 앱·과열은 반드시 한 번은 온다.

- 중단 사유 5종을 받아 **화면에 이유를 띄우고 파일을 안전하게 닫는다**
- 백그라운드로 가면 iOS 가 카메라를 뺏기 **전에** 우리가 먼저 마무리
- 미디어 서비스 재설정이면 세션을 **자동 재시작**
- `minFreeDiskSpaceLimit` 300 MB — 디스크가 차면 깨지는 대신 곱게 멈춘다
- 끊김이 있었으면 `포인트기록.txt` 머리에 그 사실을 적는다

## 시작 전 점검

녹화를 누르면 먼저 계산해서 보여준다. 경기 다 치른 뒤에 "공간이 없었다" 를 알면 늦다.

| 해상도 | 2시간 |
|---|---|
| 4K | 약 17.6 GB |
| 1080p | 약 10.0 GB |
| 720p | 약 6.4 GB |

배터리는 2시간에 약 72% 를 쓴다. 남은 분 수를 계산해 알려준다.

## 저장되는 것

```
261102_1430_경기/
  코트.mov
  포인트기록.json
  포인트기록.txt      ← 사람이 읽는 표
  포인트기록.csv      ← 편집 프로그램 챕터 마커
```

`포인트기록.csv` 의 초 값으로 영상의 그 랠리로 바로 점프한다.
녹화 전에 센 점은 초 칸이 비고 "녹화전" 으로 적힌다 — 0 이면 맨 앞으로 점프해버린다.

## 조작

| | |
|---|---|
| 자물쇠 | **득점 탭 잠금/해제.** 기본 잠김 — 거치 중 오탭 방지 |
| 화면 왼쪽/오른쪽 | 잠금을 풀면 그쪽 코트 득점 |
| ↩︎ | 마지막 1점 되돌리기 (게임·세트 경계도 정확히 복원) |
| 목록 | 포인트 기록 보기 · 표 복사 |
| 격자 | 설치 안내선 켜기/끄기 |
| ↻ | 180° 뒤집기 (거치가 거꾸로일 때) |
| ⤢ | 중계 모드 (점수판 크게) |
| ⓘ | 설치 안내 |

서브하는 쪽에 점이 켜지고, 게임포인트면 그 점수가 노란색이 된다.
코트 체인지 시점(홀수 게임 뒤, 타이브레이크 6점마다)에 안내가 뜬다.
