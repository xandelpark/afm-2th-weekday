# 디퓨져 사업 — 1차 논의 기록 (2026-09-09)

## 확정된 제약 (사장님 조건)
- 가격대 **3~10만원**
- **전자식 절대 제외** (무전원)
- 디자인 **세련**, 형식 **아날로그**
- 향은 **고급스러운 향**
- 향 전환 주기 **주 단위** (즉시 전환 필요 없음)
- 발향체는 **세라믹 오브제** 선호 (라탄 스틱 아님)
- 현재 단계: **아이디어**

## 핵심 문제 정의
향수는 매일 기분따라 고르는데, 공간의 향은 한 번 정하면 다 쓸 때까지 락인된다.

**진짜 원인은 병이 아니라 스틱.** 라탄 스틱이 오일을 머금은 스펀지라
병만 갈아도 이전 향이 며칠 섞여 나온다. 그래서 "병만 갈아끼우면 되잖아"가 시장에 없다.

→ 해법: **발향체를 카트리지에 붙여버린다.**
   `미니 보틀 + 전용 세라믹 오브제 + 실링 캡` = 한 몸

## 추가 요구사항 (2차)
**"향 맡기 싫을 땐 닫을 수 있어야 한다"**
- 기존 스틱 디퓨저는 못 끈다 (자는 동안에도, 집 비워도 계속 날아감)
- 무전원으로 이걸 해내면 결정적 차별점 + 실용신안 검토 가치
- 부수 효과: 안 쓸 때 안 닳으니 카트리지가 오래 감
  → 재구매 주기는 늘지만 **향 가짓수를 늘려 사게 되어 총 지출은 커짐**

# 2차 논의 — 위스키 세트형으로 전환 (2026-09-09)

## 컨셉 확정
**위스키 병 1개 + 잔 2~3개 세트.** 디퓨저 하나를 사면 집 세 곳에 올라간다.

### 3모드 — 용기가 곧 세기 조절
| 모드 | 구성 | 공간 |
|---|---|---|
| 강 | 병 + 긴 스틱 | 거실 |
| 약 | 잔 + 얼음(세라믹·유리 큐브) + 오일 5~10ml | 침실·현관·욕실 |
| 끔 | 병은 캡 / 잔은 코르크 뚜껑 덮기 | — |

**잔 크기 = 발향 면적 = 공간 크기.** 크기와 형태를 같이 차등한다.

| 잔 | 자리 | 내용물 |
|---|---|---|
| 록 글라스(대) | 침실 | 얼음 3~4알 |
| 노징 잔(글렌캐런형) | 책상·머리맡 | **니트 — 오일만** |
| 작은 록 글라스 | 욕실 | 얼음 1~2알 |

### 얼음은 록에, 노징 잔은 니트로 (중요)
글렌캐런에 얼음 넣은 모습이 어색한 건 편견이 아니라 **문화 코드**다.
위스키에서 노징 잔=니트, 얼음=록 글라스. 어기면 "잘못 쓰는 것"처럼 보이고,
설명이 필요한 제품은 안 팔린다. 그래서 코드를 거스르지 않고 잔을 나눈다.
- 노징 잔은 발향체 없이 액면만으로 발향 → **세척이 쉽다**(좁은 입구에 큐브 넣었으면 못 뺐다)
- 뚜껑 열었을 때 축적된 향이 확 올라오는 게 노징 잔의 하이라이트
- 애호가는 원래 두 잔을 다 갖고 있으니 세트에 둘 다 있는 게 자연스럽다
- **얼음 집게**를 세트에 넣으면 손에 안 묻고 바 도구 은유도 하나 더

### 얼음 = 발향체
- 다공성 세라믹 큐브가 오일을 머금고 발향. 잔 높이보다 낮아 뚜껑이 그냥 덮인다
- 투명감을 위해 **유리 큐브를 섞는다.** 실제 얼음도 투명도가 제각각이라 자연스럽다
- 유리는 오일을 못 머금음 → 발향 지속은 세라믹, 반짝임은 유리 (역할 분담)
- 옵션 A: 유리+세라믹 혼합 (큐브 교체로 향 전환 가능)
- 옵션 B: 전부 유리 + 잔 바닥 세라믹 원판 (비주얼 최고, 잔 통째 세척 필요)
- 잔은 살짝 프로스티드/스모크 — 지문 안 보이고 내용물이 덜 도드라짐

### 코르크 뚜껑 (= 코스터)
아기 식기 실리콘 뚜껑처럼 **아랫면에 원형 홈**을 파서 잔 테두리를 문다.
- 뒤집으면 평평한 면이 위 → 받침. 부품이 안 늘어난다
- 홈 안쪽에 얇은 실리콘 링 → 밀폐 + **코르크에 향 배임 방지** (코르크는 다공성)
- 잔 테두리 공차 흡수도 실리콘이 담당. 홈이 빡빡하면 유리가 깨진다

### 손에 안 묻는 법
**병목에 실리콘 와이퍼 링** (마스카라·립글로스 원리). 긴 스틱을 뽑을 때 오일이
훑겨 병 안으로 떨어진다. 단가 수십 원, 사출 부품.

## 가격 프레임이 뒤집혔다
"세 곳을 채운다"가 되면 8~9만원이 싸게 느껴진다. 비교 대상이 디퓨저 1개가 아니라 3개.
경쟁 제품으로 세 방 채우면 20만원+ → **이 문장이 상세페이지 맨 위로.**

| 구성 | 가격 |
|---|---|
| 싱글 (병1+잔1+뚜껑1) | 4~5만원 |
| **트리플 (병1+잔3+뚜껑3)** | **8~9만원** |
| 리필 병(200ml) | 1.8~2.5만원 (2~3개월 — 실측 후 확정) |
| 잔 추가 단품 | 1.5~2만원 |

## 안전 (설계 필수)
- **쓴맛 첨가제(비터런트)** — 술잔+얼음+액체는 진짜 술로 보인다. 원가 거의 0
- **큐브 크기 하한** — 소아 삼킴·질식 기준 초과 크기. 잔도 록글라스급으로 커짐
- 잔 각인(음용 금지) / 기본 상태 = 덮어둠

## 증발량 문제
열린 잔은 증발이 빠르다(리드 디퓨저 100ml가 2~3개월인 건 병목이 좁아서).
**하지만 우리 설계는 뚜껑이 기본 상태**라 오히려 유리하다.

- 스틱 디퓨저는 24시간 발향 → 자는 동안, 집 비운 동안 다 날아간다
- 우리는 있을 때만 연다 → 카피는 **"쓰는 만큼만 씁니다 / 안 맡는 동안엔 줄지 않습니다"**
  - ⚠️ "3배 오래 간다" 같은 **배수 표현은 실측 전까지 쓰지 말 것.**
    잔 입구가 리드 디퓨저 병목보다 넓어 열린 동안 증발이 더 빠르다. 산술 3배는 안 나온다.
    광고에 배수를 쓰면 근거를 요구받는다. 석고 시제품으로 실측 후 숫자 확정.
- 추가 대책: 잔에 붓는 양 5~10ml로 적게 / 고정제(머스크·앰버·벤조인) 비율↑ /
  휘발 느린 용매 / 노징 잔은 입구가 좁아 애초에 유리
- 뚜껑은 산화·변색 방지 역할도 한다
- 단, 열어둔 채 며칠 방치하면 마른다 → 사용법 안내 필요


## 포지셔닝 — 끄는 기능의 본질은 "선택권"

절약을 앞세우면 궁색해 보인다("덜 쓰라는 거야?"). 프리미엄이 할 말이 아니다.
**기존 디퓨저는 선택지가 없다 — 꽂는 순간부터 무조건 켜져 있다.**
우리는 자리마다 다르게 운용한다. 이게 컨트롤의 언어이고 프리미엄과 결이 맞다.

| 자리 | 운용 | 이유 |
|---|---|---|
| 거실 — 병 + 긴 스틱 | **상시** | 현관 열었을 때의 첫인상 |
| 거실 — 유리컵 | **상시 개방** | 빨리 닳아도 계속 향이 있어야 하는 자리 |
| 침실 — 록 글라스 | 잘 때만 | |
| 책상 — 노징 잔 | 앉을 때만 | 뚜껑 열 때 축적된 향이 확 올라옴 |
| 욕실 — 작은 잔 | 샤워할 때만 | |

카피 방향: **"켜둘 곳은 켜두고, 아낄 곳은 덮어둡니다."**

근거 프레임: 직장인이 깨어서 집에 있는 시간은 주 40시간 안팎(전체의 1/4).
기존 디퓨저는 나머지 3/4을 아무도 안 맡는 향에 쓴다.
→ 지속시간 표기를 **"실사용 200시간"** 식으로 바꾸면 경쟁 제품과 비교 프레임 자체가 달라진다.
("8주 vs 8주"로 싸우면 우리가 불리하다.)

### 반론과 대응
"현관 열었을 때 이미 향이 나 있어야 좋은 거 아닌가?" — 디퓨저를 사는 주된 이유 중 하나다.
→ 거실 병(+스틱)은 상시로 두면 된다. 세트 구조가 이미 답을 갖고 있다.

### 상시 개방의 실무 이슈
- **먼지** — 열린 잔은 오일 표면에 먼지가 앉는다(리드 디퓨저 공통 문제). 눈에 잘 띈다
- **산화** — 오래 열어두면 색이 탁해진다
- → 상시 개방하는 거실 잔은 **조금씩 자주 보충**하는 쪽. 사용법 안내에 반드시 포함

### 리필 주기 재계산 (기존 "월 1회"는 과했음)
거실 잔만 빨리 닳고 나머지는 천천히 줄어든다. 병은 병목이 좁아 원래 오래 간다.
200ml 한 병이 **2~3개월** 쪽일 가능성. → **월 구독은 안 맞는다.**
분기 구독이거나 구독 없이 필요할 때 구매. **구독 설계는 실측 후로 미룰 것.**
